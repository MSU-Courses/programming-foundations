# Примеры к главе 7. Функции. Процедурное программирование

В этой папке собраны все программы из [главы 7](../readme.md), каждая в отдельном файле и целиком, с `#include` и функцией `main`. Чтобы открыть пример в Visual Studio, создайте пустой консольный проект C++, добавьте в него нужный файл (или скопируйте его текст в `main.cpp`) и запустите программу клавишей F5 или Ctrl+F5. Программа `09_arena_functions.cpp` ждёт ввода урона; если вводить буквы вместо числа, она будет бесконечно повторять вопрос, и тогда её останавливают кнопкой Stop Debugging (Shift+F5) или закрытием окна консоли.

Файлы с пометкой "ОШИБКА НАМЕРЕННО" содержат ошибку, которая разбирается в главе. Исправленная версия лежит рядом.
