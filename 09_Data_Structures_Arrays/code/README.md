# Примеры к главе 9. Структуры данных. Массивы

В папке лежат все программы из главы. Каждый файл `.cpp` - самостоятельная программа с функцией `main`. Чтобы запустить пример в Visual Studio, создайте пустой консольный проект C++, добавьте в него файл примера (или скопируйте его текст в `main.cpp`) и запустите программу клавишей `Ctrl+F5`. Программы `03_level_by_number.cpp` и `10_level_input_check.cpp` ждут ввода номера уровня. Ни одна программа не зацикливается; если программа всё же не завершается, остановите её сочетанием `Shift+F5` или закройте окно консоли.
