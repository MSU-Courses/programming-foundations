# Примеры к главе 10. Структуры данных. Двумерные массивы

В папке лежат все программы из главы. Каждый файл `.cpp` - самостоятельная программа с функцией `main`. Чтобы запустить пример в Visual Studio, создайте пустой консольный проект C++, добавьте в него файл примера (или скопируйте его текст в `main.cpp`) и запустите программу клавишей `Ctrl+F5`. Программы не ждут ввода и не зацикливаются; если программа всё же не завершается, остановите её сочетанием `Shift+F5` или закройте окно консоли.

| Файл | Раздел главы | Что показывает |
| --- | --- | --- |
| [01_level_map.cpp](01_level_map.cpp) | Доступ к клетке, Обход двумерного массива | Двумерный массив `char map[4][6]`, доступ `map[row][col]`, вывод карты |
| [02_count_coins.cpp](02_count_coins.cpp) | Обход двумерного массива | Подсчёт монет вложенными циклами |
| [03_find_exit.cpp](03_find_exit.cpp) | Поиск клетки | Поиск выхода, строка и столбец в двух переменных |
| [04_map_functions.cpp](04_map_functions.cpp) | Двумерный массив как параметр, Пример: проверка соседних клеток и границ карты | `printMap` и `canMoveTo` с параметром `char map[][COLS]` |
| [05_has_symbol.cpp](05_has_symbol.cpp) | Функция поиска клетки | `return` внутри вложенных циклов останавливает поиск |
| [06_dungeon_levels.cpp](06_dungeon_levels.cpp) | Многомерный массив | Трёхмерный массив `char dungeon[2][3][5]`, обход тремя вложенными циклами |
