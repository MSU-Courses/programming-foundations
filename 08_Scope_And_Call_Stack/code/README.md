# Примеры к главе 8. Область видимости и стек вызовов

В этой папке собраны все программы из [главы 8](../readme.md), каждая в отдельном файле и целиком. Чтобы открыть пример в Visual Studio, создайте пустой консольный проект C++, добавьте в него нужный файл (или скопируйте его текст в `main.cpp`) и запустите программу клавишей F5 или Ctrl+F5. Ни одна из программ не ждёт ввода.

Файлы с пометкой "ОШИБКА НАМЕРЕННО" содержат ошибку, которая разбирается в главе. Исправленная версия лежит рядом.
