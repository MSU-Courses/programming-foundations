## Ретроспектива

В предыдущей главе программа арены была разделена на функции. Функция `countHits()` рассчитывала количество ударов, получая здоровье врага и урон через параметры и возвращая результат с помощью `return`.

При работе с несколькими функциями необходимо учитывать область видимости переменных, продолжительность их существования и порядок выполнения вызовов. Эти механизмы объясняют, почему разные функции могут использовать одинаковые имена переменных, но не могут напрямую обращаться к локальным переменным друг друга.

В главе последовательно рассматриваются область видимости, время жизни переменных и стек вызовов.

> Исходный код примеров расположен в папке [code](code/). Каждый файл `.cpp` содержит самостоятельную программу.

## Доступ к локальным переменным другой функции

Рассмотрим программу, в которой у врага `100` единиц здоровья, а каждый удар наносит `30` единиц урона. Функция `countHits()` должна определить необходимое количество ударов.

Функция `countHits()` пытается использовать константу `ENEMY_HEALTH`, объявленную в `main()`, вместо получения значения через параметр:

```cpp
#include <iostream>

int countHits(int damage) {
    int health = ENEMY_HEALTH;
    int hits = 0;

    while (health > 0) {
        health = health - damage;
        hits = hits + 1;
    }

    return hits;
}

int main() {
    const int ENEMY_HEALTH = 100;
    std::cout << countHits(30) << '\n';
    return 0;
}
```

Программа не компилируется. При обработке строки `int health = ENEMY_HEALTH;` компилятор сообщает, что имя `ENEMY_HEALTH` не объявлено в доступной области[^1].

Константа определена внутри `main()`, поэтому её имя недоступно в `countHits()`. Изменение порядка определения функций не устраняет ошибку: _локальные имена одной функции не становятся доступными внутри другой_.

Для передачи значения следует использовать параметр функции. В исправленном варианте `countHits()` получает здоровье врага через параметр `health`:

```cpp
#include <iostream>

int countHits(int health, int damage) {
    int hits = 0;

    while (health > 0) {
        health = health - damage;
        hits = hits + 1;
    }

    return hits;
}

int main() {
    const int ENEMY_HEALTH = 100;
    std::cout << countHits(ENEMY_HEALTH, 30) << '\n'; // 4
    return 0;
}
```

При вызове `countHits(ENEMY_HEALTH, 30)`,

- параметр `health` получает значение `100`,
- параметр `damage` - значение `30`.

Функция последовательно уменьшает `health` и возвращает результат `4`. Константа `ENEMY_HEALTH` в `main()` не изменяется.

Разница между этими вариантами определяется областью видимости имён.

## Область видимости

**Область видимости (scope)** - часть исходного кода, в которой доступно объявленное имя, например имя переменной[^2]. Объявление переменной не делает её имя доступным во всей программе.

### Локальные переменные и вложенные блоки

**Локальная переменная (local variable)** - переменная, объявленная внутри функции или блока. В рассматриваемых примерах её имя доступно от места объявления до конца соответствующего блока[^2]. Блок содержит инструкции, заключённые в фигурные скобки `{` и `}`, например тело функции или условного оператора `if`.

Параметры функции также имеют локальную область видимости. Поэтому параметр `health` внутри `countHits()` и константа `ENEMY_HEALTH` внутри `main()` являются разными объектами, даже если их значения совпадают.

В пределах одной функции вложенный блок имеет доступ к именам внешнего блока. Обратное неверно: имена, объявленные только во вложенном блоке, недоступны за его пределами. Это можно показать на примере восстановления здоровья героя:

```cpp
int health = 30;

if (health < 50) {
    int bonus = 20;
    health = health + bonus;
}

std::cout << health << '\n'; // 50
// std::cout << bonus << '\n'; // Ошибка: имя bonus здесь недоступно.
```

Переменная `health` объявлена до блока `if`, поэтому внутри блока её можно читать и изменять. Переменная `bonus` объявлена внутри `if` и доступна только в этом блоке. После выполнения условия `health` содержит `50`, но имя `bonus` за пределами блока недоступно.

Если значение `bonus` необходимо использовать после `if`, переменную следует объявить во внешнем блоке:

```cpp
int health = 30;
int bonus = 0;

if (health < 50) {
    bonus = 20;
    health = health + bonus;
}

std::cout << bonus << '\n'; // 20
```

При этом объявлять все переменные в начале функции не требуется. _Область видимости переменной рекомендуется ограничивать блоком, в котором она необходима._ Это уменьшает количество доступных имён и упрощает анализ кода[^3].

### Переменная цикла for

Область видимости также ограничивает использование счётчика цикла. Например, следующая программа выводит номера трёх врагов:

```cpp
for (int enemy = 1; enemy <= 3; enemy = enemy + 1) {
    std::cout << "Enemy " << enemy << '\n';
}

// std::cout << enemy << '\n'; // Ошибка: имя enemy здесь недоступно.
```

Переменная `enemy` объявлена в заголовке `for`. Её имя доступно в условии, выражении изменения счётчика и теле цикла. После завершения оператора `for` имя `enemy` становится недоступным[^2]. Если полученное значение необходимо после цикла, его следует сохранить в переменную внешнего блока.

Ограниченная область видимости счётчика помогает избежать ошибок при его повторном использовании. Рассмотрим три волны, в каждой из которых должны появиться два врага. Если счётчик объявлен перед внешним циклом, его значение сохраняется между волнами:

```cpp
int enemy = 1;

for (int wave = 1; wave <= 3; wave = wave + 1) {
    while (enemy <= 2) {
        std::cout << "Wave " << wave << ", enemy " << enemy << '\n';
        enemy = enemy + 1;
    }
}
```

Программа выводит двух врагов только в первой волне. После неё `enemy` принимает значение `3`, поэтому в следующих волнах условие `enemy <= 2` сразу оказывается ложным.

Для исправления достаточно объявить счётчик во внутреннем цикле. Тогда каждая волна выполняет собственный цикл появления врагов:

```cpp
for (int wave = 1; wave <= 3; wave = wave + 1) {
    for (int enemy = 1; enemy <= 2; enemy = enemy + 1) {
        std::cout << "Wave " << wave << ", enemy " << enemy << '\n';
    }
}
```

В результате выводятся все шесть врагов. При каждой итерации внешнего цикла внутренний цикл начинается с `enemy = 1` и выводит двух врагов.

## Время жизни переменной

Область видимости определяет, где имя переменной доступно в коде. Отдельная характеристика определяет, как долго переменная существует во время выполнения программы.

**Время жизни переменной (lifetime)** - период выполнения программы, в течение которого переменная существует. Обычная локальная переменная в примерах этой главы создаётся при выполнении объявления и уничтожается при выходе из соответствующего блока[^4].

В следующем примере функция `spawnEnemy()` увеличивает счётчик появившихся врагов:

```cpp
#include <iostream>

void spawnEnemy() {
    int spawned = 0;
    spawned = spawned + 1;
    std::cout << "Spawned: " << spawned << '\n';
}

int main() {
    spawnEnemy();
    spawnEnemy();
    spawnEnemy();
    return 0;
}
```

Результат:

```text
Spawned: 1
Spawned: 1
Spawned: 1
```

При каждом вызове `spawnEnemy()` создаётся новая локальная переменная `spawned` со значением `0`. Затем значение увеличивается до `1` и выводится на экран. После завершения функции переменная уничтожается, поэтому следующий вызов повторяет вычисление с начального значения.

Для накопления общего количества врагов переменная должна сохраняться между вызовами. Её можно объявить в `main()`, передавая текущее значение в функцию и получая обновлённое:

```cpp
#include <iostream>

int spawnEnemy(int spawned) {
    spawned = spawned + 1;
    std::cout << "Spawned: " << spawned << '\n';
    return spawned;
}

int main() {
    int totalSpawned = 0;
    totalSpawned = spawnEnemy(totalSpawned);
    totalSpawned = spawnEnemy(totalSpawned);
    totalSpawned = spawnEnemy(totalSpawned);
    return 0;
}
```

Последовательные вызовы выводят `Spawned: 1`, `Spawned: 2` и `Spawned: 3`. Переменная `totalSpawned` сохраняется в `main()` между вызовами. Параметр `spawned` при каждом вызове получает копию текущего значения, после чего функция возвращает результат.

_Область видимости и время жизни описывают разные свойства._ Область видимости определяет, в какой части исходного кода доступно имя. Время жизни определяет, когда переменная существует при выполнении программы. Например, во время вызова `spawnEnemy()` переменная `totalSpawned` из `main()` продолжает существовать, но её имя недоступно внутри `spawnEnemy()`.

## Одинаковые имена и сокрытие

Локальные переменные разных функций могут иметь одинаковые имена, поскольку их области видимости не пересекаются. Другая ситуация возникает при повторном объявлении имени во вложенном блоке.

**Сокрытие имени (shadowing)** - ситуация, при которой объявление имени во вложенном блоке скрывает одноимённое объявление из внешнего блока[^2]. Внутри вложенного блока использование этого имени относится к новой переменной.

Рассмотрим подсчёт общего количества ударов в трёх волнах. Функция `countHits(100, 30)` возвращает `4` для каждой волны:

```cpp
int totalHits = 0;

for (int wave = 1; wave <= 3; wave = wave + 1) {
    int totalHits = countHits(100, 30);
}

std::cout << "Total hits: " << totalHits << '\n'; // 0
```

Программа выводит `Total hits: 0`, хотя функция трижды возвращает `4`. Объявление `int totalHits` внутри цикла создаёт новую переменную, которая скрывает внешнюю. Значение внешней переменной не изменяется, а внутренняя переменная уничтожается после каждой итерации.

Чтобы накапливать результат, необходимо изменять ранее объявленную переменную, а не создавать новую:

```cpp
int totalHits = 0;

for (int wave = 1; wave <= 3; wave = wave + 1) {
    totalHits = totalHits + countHits(100, 30);
}

std::cout << "Total hits: " << totalHits << '\n'; // 12
```

Одинаковые имена в независимых функциях допустимы. Однако во вложенных блоках повторное объявление имени может привести к незаметной ошибке, поэтому такого сокрытия рекомендуется избегать[^3].

## Глобальные переменные

Помимо локальных переменных, C++ допускает объявление переменных вне функций. В рассматриваемой программе функции, расположенные после такого объявления в том же файле, могут обращаться к переменной по её имени.

**Глобальная переменная (global variable)** - переменная, объявленная вне функций, на уровне файла. В простых программах этой главы она доступна от места объявления до конца файла и существует в течение всего выполнения программы[^2][^4].

Например, функцию восстановления здоровья можно реализовать с помощью глобальной переменной:

```cpp
#include <iostream>

int playerHealth = 50;

void heal() {
    playerHealth = playerHealth + 20;
}

int main() {
    heal();
    std::cout << playerHealth << '\n'; // 70
    return 0;
}
```

Функция `heal()` изменяет `playerHealth`, не получая аргументов. Такое решение допустимо, однако вызов `heal()` не показывает, от каких данных зависит функция и какое состояние она изменяет. Если одну глобальную переменную изменяют несколько функций, поиск причины ошибочного значения усложняется.

Для этой задачи предпочтительно передавать здоровье аргументом и возвращать обновлённое значение:

```cpp
int heal(int health) {
    return health + 20;
}

// Внутри main():
playerHealth = heal(playerHealth);
```

Вызов с присваиванием явно показывает, какая переменная обновляется. Изменяемые глобальные переменные поддерживаются языком, но их рекомендуется избегать, если задачу можно решить через параметры и возвращаемое значение[^3].

> [!TIP]
> Глобальная константа, например `const int MAX_HEALTH = 100;`, допускает чтение значения из функций, но запрещает его изменение. Поэтому общие неизменяемые значения не создают проблемы скрытого изменения состояния.

## Стек вызовов

Каждая функция имеет собственные локальные переменные. При вложенных вызовах программа должна сохранять состояние незавершённых функций и возвращаться к ним в установленном порядке.

### Кадры стека

В программе арены функцию `countHits()` можно дополнить вызовом `calculateDamage()`, который рассчитывает урон с учётом защиты врага:

```cpp
#include <iostream>

int calculateDamage(int attack, int defense) {
    int damage = attack - defense;

    if (damage < 1) {
        damage = 1;
    }

    return damage;
}

int countHits(int enemyHealth, int attack, int defense) {
    int hits = 0;

    while (enemyHealth > 0) {
        enemyHealth = enemyHealth - calculateDamage(attack, defense);
        hits = hits + 1;
    }

    return hits;
}

int main() {
    int hits = countHits(100, 30, 10);
    std::cout << "Hits: " << hits << '\n'; // 5ƒ
    return 0;
}
```

За один удар враг получает `30 - 10 = 20` единиц урона. Для уменьшения здоровья со `100` до `0` требуется пять ударов.

При вычислении первого удара `main()` вызывает `countHits()`, а `countHits()` вызывает `calculateDamage()`. Пока выполняется `calculateDamage()`, два предыдущих вызова ещё не завершены. Программе необходимо сохранить их состояние и сведения о месте продолжения выполнения.

**Стек вызовов (call stack)** - структура данных, в которой хранятся сведения о незавершённых вызовах функций, необходимые для продолжения выполнения после возврата[^5].

**Кадр стека (stack frame)** - набор данных, связанных с одним вызовом функции. В общей модели кадр содержит необходимые сведения об аргументах, локальных переменных и месте продолжения выполнения после возврата[^5].

Кадры добавляются и удаляются по принципу _последним пришёл - первым ушёл (last in, first out, LIFO)_: новый вызов размещает кадр на вершине стека, а завершение функции удаляет верхний кадр. Последовательность выполнения программы:

1. При начале выполнения `main()` создаётся её кадр.
2. При вызове `countHits()` создаётся следующий кадр.
3. При вызове `calculateDamage()` поверх предыдущих размещается третий кадр.
4. После возврата значения `20` из `calculateDamage()` её кадр удаляется, а `countHits()` продолжает выполнение.
5. После пяти ударов `countHits()` возвращает `5`, и выполнение продолжается в `main()`.

![Три последовательных состояния стека вызовов main, countHits и calculateDamage](../08/images/fig-call-stack.svg)

_Рисунок 8.2. Новый вызов добавляет кадр в стек, а возврат удаляет верхний кадр_

Во время выполнения `calculateDamage()` переменные `enemyHealth` и `hits` функции `countHits()` продолжают существовать, поскольку её вызов ещё не завершён. Однако имена этих переменных недоступны внутри `calculateDamage()`. _Стек вызовов отражает последовательность незавершённых вызовов, а область видимости определяет доступность имён в исходном коде._

Цепочку вызовов можно изучить в отладчике Visual Studio. Окно _Call Stack_ отображает функции, вызовы которых привели к текущему месту остановки программы[^6]. Для проверки используется пример из [раздела "Кадры стека"](#кадры-стека), сохранённый в файле [`07_call_stack.cpp`](code/07_call_stack.cpp).

1. Откройте файл `07_call_stack.cpp` и установите точку останова на строке `return damage;` в функции `calculateDamage()`.
2. Запустите отладку клавишей `F5`. Выполнение остановится перед выходом из функции.
3. Откройте окно `Debug > Windows > Call Stack` или используйте сочетание клавиш `Ctrl+Alt+C`.
4. В окне Call Stack проверьте порядок функций: `calculateDamage`, `countHits`, `main`. Дополнительно могут отображаться системные вызовы.
5. В окне `Locals` для `calculateDamage()` проверьте значения `attack = 30`, `defense = 10` и `damage = 20`.
6. Выберите кадр `countHits` двойным щелчком. При первом ударе в этом кадре значения `enemyHealth` и `hits` равны `100` и `0` соответственно.

Выбор кадра позволяет просмотреть связанные с ним переменные, но не изменяет текущую точку выполнения программы[^6]. Окно Call Stack помогает определить, какая функция вызвала текущую и какие значения были доступны в вызывающем коде.

## Типичные ошибки

- _Обращение к локальной переменной другой функции_. Необходимое значение следует передать через аргумент.
- _Обращение к переменной за пределами её блока_. Если значение требуется позднее, объявление необходимо разместить во внешнем блоке.
- _Сокрытие одноимённой переменной_. Повторное указание типа `int` создаёт новую переменную вместо присваивания ранее объявленной.
- _Попытка сохранить значение обычного локального счётчика между вызовами_. Общее значение можно хранить в вызывающей функции и обновлять через возвращаемый результат.
- _Изменение общей глобальной переменной из нескольких функций_. Когда это возможно, данные следует передавать через параметры и возвращаемое значение.

## Резюме

1. Область видимости определяет, где в исходном коде можно использовать имя переменной.
2. Локальные переменные функции недоступны по имени из других функций; значения передают через аргументы.
3. Вложенный блок видит имена внешнего блока, но не наоборот; счётчик, объявленный в `for`, доступен только в пределах этого цикла.
4. Время жизни определяет, когда переменная существует; обычная локальная переменная создаётся заново при каждом вызове функции.
5. Сокрытие возникает, когда объявление во вложенном блоке использует имя внешней переменной.
6. Глобальные переменные позволяют обращаться к общим данным, но их изменение из разных функций затрудняет поиск ошибок.
7. Стек вызовов хранит сведения о незавершённых вызовах; новый кадр добавляется при вызове и убирается при возврате.
8. Окно Call Stack в Visual Studio показывает цепочку вызовов и помогает просматривать значения переменных разных кадров.
